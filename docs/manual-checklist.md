# 白饭下载器 · 人工勾选单

> 自动化能覆盖的都进了 `tools/accept.py`（来源版本自动化报告（正式发布前仍需 Windows 11 重测））。
> 这份只剩**必须真人用鼠标点、用键盘敲、用耳朵听**的，一条大概 30 秒。
> 打勾方式：通过打 `[x]`，不通过写一行现象，我按现象改。

## 0. 界面外观（10 秒）

- [ ] 最左边有一列小圆点：下载中蓝、下完绿、上传中绿点带圈、错误红、等待灰
- [ ] 备注列默认宽度刚好能放下灰色提示「＋ 双击这里写备注」，不会白占一大片
- [ ] 新建任务输入框里右键 → 菜单是中文（撤销/复制/粘贴/全选…），不是 Undo/Redo
- [ ] 任务正在上传时点开桌宠气泡 → 顶部写「给鱼群分饭 N 个」，列表里有 ↑ 上传速度和已传量
- [ ] 同时有下载和做种时，桌宠底部进度条只反映**正在下载**的进度，不会被做种的 100% 拉满
- [ ] 下完的任务状态显示「开饭了 ✓」；不会把完整文件误报成「没吃干净 ✗」
- [ ] 已经下完的任务被暂停/重启后，仍然留在「开饭了」并显示 100%，**不会掉进「放下筷子」**
- [ ] 左栏「种子库」的图标是抱小箱子（带 U/BT）那张；「噎住了」换成红色叉那张
- [ ] 点「种子库」→ 只弹历史种子列表，那一行**不会**出现带四个黑角的焦点框
- [ ] 任务**还没下完**时点「打开」/双击那一行 → 不启动播放器，
      鼠标旁/桌宠冒小气泡「尚未下载完成（xx%），下完再打开」；下完再点才是正常打开
- [ ] 下载中的任务点「打开文件夹」仍然能打开目录（这个不拦）
- [ ] 把某个已经下完的文件**删掉** → 等几秒，那行变成**黄色三角感叹号**（鼠标悬停有说明）
- [ ] 点一次「大小」表头 → 按大小排，第一次弹一句"按住 Shift…"的提示
- [ ] 按住 Shift 再点「名称」表头 → 先按大小、再按名称；表头 tooltip 里写着当前排序
- [ ] 左边筛选列表和右边任务表格**紧挨着**，中间没有一条白色空带（v0.9.5 修的就是这个）
- [ ] 拖「大小」和「进度」中间那条分隔线往右 → **右边的列跟着往右走**，「大小」变宽、「名称」宽度不变；
      拖到超出窗口宽度时出现横向滚动条（以前是右边不动、反而把「名称」压窄）
- [ ] 把「大小」拖回原位 → 横向滚动条自己消失
- [ ] 拖宽一列后**再拖一次**，宽度要接着上次继续变，不会跳回原来的宽度
- [ ] 双击那条分隔线 → 宽度**不会变**（以前会被 Qt 拍回"合适宽度"，像被复原）
- [ ] 把窗口拉宽 → 多出来的地方是右端那条浅紫渐变，不是白色空隙
- [ ] 故意把「名称」拖得很窄 → 右边露出空白：应该是**浅蓝到淡紫的渐变 + 几颗小白点**，
      不是纯黑也不是死白；表头那一条跟表头同色

## 1. 托盘与退出（约 1 分钟）

- [ ] 右键托盘图标 → 菜单能弹出，中文不乱码
- [ ] 点「显示主窗口」→ 窗口回到前台
- [ ] 点「退出」→ 进程消失（任务管理器里 `BaiFanDownloader.exe` 和 `aria2c.exe` 都没了）
- [ ] 菜单栏「文件 → 退出」也要真的退出（v0.10.17 修的就是这个死按钮）
- [ ] 关掉主窗口（点 ×）→ 托盘图标还在，正在下的任务继续跑

## 2. 桌宠（约 2 分钟）

- [ ] 拖一个下载链接到桌宠**头上**松手 → 弹出新建任务并预填链接
- [ ] 单击桌宠 → 冒出进度气泡；**再单击一次 → 收起气泡并呼出主窗口**（不会再弹一个内容一样的框）
- [ ] 气泡开着时点屏幕空白处/别的窗口 → **白框立刻收起**；桌宠还留着，按贴边缓冲慢慢收
- [ ] 双击桌宠 → 直接用剪贴板里的链接建任务
- [ ] 故意再把**昨天已经下完的那个链接**贴一次 → 弹「这个好像下过」，
      里面写着日期和文件位置；点「取消」不会加进去，点「还是再下一份」才加
- [ ] 菜单「任务」→「复制链接」下面就是「AI 调用接口…」，点开有「复制完整说明」，
      复制出来的文本里端口和 token 都是填好的
- [ ] 把桌宠拖到屏幕左边缘松手 → 收成一条发色蓝边；鼠标碰它 → 展开；拖回中间 → 不再自动收
- [ ] **贴边唤出后别急着动**：鼠标碰蓝边展开后，停 3~5 秒不动也不会立刻收回去；够时间把鼠标移到头像上点下去
- [ ] 右键桌宠 → 菜单最下面是「退出整个程序」，点了整个程序退出（aria2c 也一起停）
- [ ] 右键桌宠 → 菜单里有「打开主窗口 / 暂停全部 / 收成一条边 / 隐藏桌宠 / 退出整个程序」
- [ ] 重启程序 → 桌宠出现在**上次拖到的位置**，不是默认右下角
- [ ] 贴边状态下点桌宠开面板 → 气泡完整可见，没有被推出屏幕外
- [ ] 没任务时是**带字的那张**（Ciallo～）；真正开始下载后**全程都是半张脸**，不管几个任务在同时下
- [ ] 加一个**磁力链接**：先出来的是**端着碗等**那张（在取种子），真任务开始跑之后变半张脸
- [ ] 下载完成那一刻 → 换成**指着你「没吃饱喵」**那张，停约 12 秒回招呼图；气泡写「第 N 碗下完了，没吃饱喵！」
- [ ] **完成那一刻就回**（不用等做种一小时）：下完盯着看 15 秒，第 12 秒左右应该自己换回招呼图
- [ ] 今天下完第 3 个之后 → 桌宠**待命时躺着**（躺沙发那张），不再站着
- [ ] 关掉程序重开 → 今天已经下完 3 个的话，待命还是躺着（不是从头数）
- [ ] 单击弹出的进度气泡，**手别碰它，等 10 秒** → 自己收起来
- [ ] 气泡开着的时候拖桌宠去屏幕边上 → 气泡跟着收掉，只剩蓝边
- [ ] 气泡开着的时候全屏放个视频 → 气泡和桌宠一起消失，退出全屏一起回来
- [ ] 设置 → **桌宠** 页：六行各一张缩略图，右上是「内置」；点「换张图…」随便挑一张
      **白底的 JPG 截图** → 缩略图立刻变成抠好底的图，标签变蓝「我自己换的」，
      桌宠当场跟着换（不用重启）
- [ ] 换完按「取消」→ 桌宠退回原来那张（换图是即时生效的，取消要能撤销）
- [ ] 「还原」那一行 → 变回内置图；「全部还原」→ 六行全回内置
- [ ] 故意选一个 txt 改名成 .png → 弹提示说读不进来，程序不崩、原来的图还在

## 3. 完成通知（约 1 分钟，要真的下一个文件）

- [ ] 只勾「声音」下一个文件 → 只有"叮"，没有气泡和系统通知
- [ ] 只勾「系统通知」→ 右下角 Windows 通知弹出，程序自己的气泡不出现
- [ ] 只勾「气泡」→ 只有程序自己的卡片，系统通知不弹
- [ ] 三个全勾 → 三个都在，声音不卡顿
- [ ] 设置里换成别的音效 → 下一个文件时听到的是换的那个
- [ ] 气泡上的「打开文件夹」「打开」点了真的能打开

## 4. 磁力链接（约 2 分钟，新改的，这条最重要）

- [ ] 复制一条磁力链接，双击桌宠（或粘贴进新建任务）→ 开始下
- [ ] 元数据到了之后，列表里显示成「年月 + 关键词」（如 `2026年08月 彼女催眠 …`），
      鼠标悬停能看到原文件名；双击打开/做种仍然正常
- [ ] 设置 → 常规 → 取消「自动给已下载的种子任务改名为核心内容」→ 新加的任务保持原文件名
- [ ] **中间不该弹任何"完成"提示**：没有声音、没有系统通知、没有气泡
- [ ] 列表里那条「种子菜单」很快自己消失，紧接着出现真正的视频任务在下载
- [ ] 全程只有最后真下完时响一次

> 以前磁力会响两次：第一次是"种子元数据抓到了"，第二次才是真下完。现在第一次静默。

## 5. 种子（约 2 分钟，需要一个多文件夹的 .torrent）

- [ ] 拖一个 `.torrent` 进主窗口 → 弹出的是**文件夹树**：文件夹可以展开/收起，
      不是一长排平铺的文件（v0.10.18 改的，对标比特彗星）
- [ ] 文件夹行显示**里面所有文件的合计大小**；勾一个文件夹 → 里面的文件全部勾上
- [ ] 取消文件夹里某一个子文件 → 父文件夹变成**半选**（一个小方块）
- [ ] 全选按钮上带文件总数，例如「全选(40)」
- [ ] 只勾一部分 → 下完只有勾的那几个，未勾的不占空间
- [ ] 全不勾就点确定 → 明确提示"一个都没选"，不建空任务
- [ ] 左栏分类顺序：全部饭碗 / 打饭中 / 排队等饭 / 放下筷子 / 开饭了！！ / 给鱼群分饭（下挂种子库）/ 噎住了
- [ ] 左栏「给鱼群分饭」下面有一条「种子库 (N)」；点开只有**来源**：
      名称 / 类型（磁力 / 种子文件）/ 添加时间 / 来源，**没有文件大小**
- [ ] 用一个 `.torrent` 的 http 链接建任务 → 任务列表里**不会**出现一条
      「xxx.torrent 已完成」的假文件；来源进种子库，真正的 BT 任务照常出现
- [ ] 种子库里选中一条 →「重新下载」→ 回主窗口按原磁力/种子重新建下载任务
- [ ] 种子库「删除备案」只删磁力/.torrent 来源，已经下好的文件不动

## 6. 关掉再开（约 1 分钟，最容易出问题的一条）

- [ ] 下一个大文件，下到一半点 ×（关窗口）
- [ ] 托盘还在 → 任务继续在下（看速度）
- [ ] 托盘右键退出 → 再双击启动 → 未完成的任务还在列表里
- [ ] 点继续 → 从断点续传，不是从头开始

- [ ] 设置 → BitTorrent：做种时间默认 **60 分钟**；减到 0 显示「不做种」，不是「不限」
- [ ] 工具栏「AI 调用接口」「大肥鱼干饭手册」前面的图标看得清（28px，不是小点点）
- [ ] 下半部分详情面板能把鼠标放在上边界自由拖动（大约 20%~30% 也行），不会被一下收掉
- [ ] 详情面板右上角的 ▾ 点一下收起、再点 ▴ 恢复原来的高度
- [ ] 备注：箭头实际在详情标签栏**左上角**（桌宠在右下角会挡右上角）；拖矮后常规页出现滚动条，字不重叠
- [ ] 设置 → 桌宠页顶部说明里写清了：作者已放多张图、推荐正方形/长边 4096、文件 10MB 内、可用 AI 生成

- [ ] 设置 → 限速：下载默认「不限」；**全局上传 / 单任务上传默认都是 100 KB/s**
- [ ] 新建任务对话框里「上传限速」默认也是 100 KB/s（下拉里有 50/100/200 KB/s）

- [ ] 已经下完但没在传的任务：点「开始」或右键「给鱼群分饭」→ 先校验文件、然后开始上传（不会重下）
- [ ] 开启上传后**不会**多出一条完成记录、不会响完成提示音、桌宠不会弹"又完成一碗"

## 已知的、不用你重复验的

这些自动化已经验过，你看到异常再说：

- 冷启动、单实例、关窗口不杀引擎、`app.log` 无异常
- 批量链接（空格/换行/Tab）、分享文案提链接、磁力识别、重复去重
- 双击打开：视频/图片→默认程序，目录/多文件/exe/zip→资源管理器
- 暂停/继续/续传/删除任务（保留文件 / 连文件进回收站）
- 限速与并发是否真的下发给 aria2、限速是否真的压住速度
- 中文空格路径、超长中文文件名、404 报错、同链接两个任务
- 桌宠状态规则、贴边、全屏避让（32+5 项断言）
- 备注：列位置、双击进编辑、存盘、刷新不丢、清空、超长截断、按备注搜索、AI 读写备注
- 磁力「先取种子」那一步不弹通知、不计碗数、不触发校验（`is_meta`）
- 桌宠换图规则、1/3 彩蛋概率、气泡自动收/全屏收/贴边收（56 项断言）
- 桌宠换图本身：白底抠图、单张覆盖、还原、取消回滚、素材库铺开（33 项断言）
- 选项数值：推荐值文案、各项上下限、aria2 拒绝 17 的实测、越界值回夹（12 项断言）
